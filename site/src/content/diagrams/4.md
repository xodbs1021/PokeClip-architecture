> 원본 SysA(시스템 아키텍처) 다이어그램을 반응형 문서로 재구성한 뷰. 클라이언트 3 · 서비스 6 · 데이터 3 — SA와 같은 시스템의 배포 관점. CDN·인프라 배치는 5 CA에서.

## Client Tier

- **OBS 플러그인** (스트리머 PC · 네이티브 — C++ · libobs/FFmpeg/libsrt): SRT+TS 멀티트랙 동시 송출(본방 인코더 공유) · 소스별 오디오 캡처→AAC 인코딩(최대 10트랙) · 핫키 마킹·트랙 매니페스트(컨트롤 채널) · 자동 재연결·송출 통계
- **웹 대시보드** (스트리머+편집자 공용 — React·TypeScript): 라이브 뷰(DVR 플레이어·점프카드 SSE·채팅 차트) · 클립 에디터·보관함(웨이브폼·미리듣기·승인) · VOD 뷰(60일)·온보딩·설정(권한·템플릿)
- **운영 콘솔** (운영자 전용 — 동일 SPA 내 권한 분기): 계정 관리·사용 통계 · 시스템 모니터링(인제스트·큐·스토리지) · 장애·업로드 실패 대응

## Backend Service Cluster — 서비스 6종 (컨테이너)

### Auth·Account Service — Java · Spring Boot

구글 OAuth 로그인·JWT 발급 · 편집자 초대·권한 토글 · 채널 등록(치지직·SOOP)·유튜브 토큰 보관 · 스트림 키 발급·검증

### Clip Service — Java · Spring Boot

점프카드 생성·SSE 푸시 · 레시피 CRUD·템플릿(=구간 빈 레시피) · 웨이브폼·무음 필터(구간 디코드) · 승인 플로우·클립·잡 상태 관리

### Media Origin ⭐ — Go (직접 구현 · MediaMTX 참조 · BE1 전담)

SRT 수신(streamid·passphrase)·TS 디먹스 · CMAF 세그먼트·LL-HLS 서빙(DVR 1h 윈도우) · 멀티오디오 rendition·세그먼트 S3 실시간 적재 · VOD 매니페스트 확정·방송 시작/종료 이벤트

### Chat Collector·Analytics — TypeScript · Node (기존 자산)

치지직(공식 Open API/비공식 WS)·SOOP WS · 플랫폼별 시차 보정→인제스트 타임라인 정렬 · 채팅 차트 집계(윈도우·참여율)·아카이브 · 하이라이트 탐지→점프카드 생성 요청

### Render·Upload Worker — Java · Spring (FFmpeg 프로세스 지휘)

클립 렌더(비율 5종·자막 번인·amix·-14 LUFS) · 유튜브 resumable 업로드·CC 등록(스트리머 토큰) · 일일 쿼터 관리·재시도·상태 보고

### AI Worker — Python · faster-whisper

선택 트랙 자막 생성(vad_filter — 무음 스킵) · 자막 기반 추천 제목 생성 · 결과 저장→Clip Service 상태 갱신

**큐 4종 (SQS / Redis Streams)** — ① 방송이벤트 큐: Media Origin이 방송 시작·종료를 발행 → **2소비자 팬아웃**(수집기 트리거 · Clip Service) ② 렌더 잡 큐 ③ AI 잡 큐 ④ 업로드 잡 큐: 생산자 = Clip Service, 소비자 = Render·AI Worker — 비동기 파이프라인. 워커 결과·잡 상태는 **Clip Service 경유로만 영속화**(계약1·8) — 워커는 PostgreSQL에 직접 쓰지 않는다.

## Data Tier

- **PostgreSQL**: 계정·권한 · 채널 연동 · 레시피 · 점프카드 · 클립·잡 상태 · 하이라이트 지표 · 자막·제목 (소유 서비스: Auth·Clip·Chat — 워커 직접 쓰기 없음)
- **Redis**: 세션 · 라이브 상태 · 채팅 집계 캐시 · SSE 팬아웃(pub/sub)
- **S3**: 세그먼트 한 벌(핫 1h 롤링·콜드 전체) · VOD(60일) · 클립(영구) · 채팅 아카이브

## 외부 API (3rd-Party)

Google OAuth(로그인·채널 토큰) · YouTube Data API(videos.insert 1600u·captions 400u) · CHZZK(공식 Open API·Session/비공식 WS) · SOOP(채팅 WS) · CloudWatch(전 서비스 로그·메트릭) · Secrets Manager(DB·토큰·키)

## SA ↔ SysA 매핑 (같은 시스템 · 다른 줌 레벨)

플러그인 → Media Origin(SRT)+Auth(스트림 키)+Clip(컨트롤 채널) | 온보딩·설정 → Auth·Account | 라이브 뷰 → Media(LL-HLS·DVR)+Clip(SSE)+Chat(차트) | 에디터·보관함 → Clip→큐→Render·AI | VOD → Media Origin | 운영 콘솔 → 전 서비스(CloudWatch 지표)
