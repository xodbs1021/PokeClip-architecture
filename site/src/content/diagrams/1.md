> 정보 구조(IA) 다이어그램을 EDGE 슬라이드 문법(순수 모노크롬 트리)으로 재구성한 뷰. 로그인 → 메인 대시보드 → 좌·우 기능 영역으로 대분기하는 웹 대시보드 + OBS 플러그인 화면 트리. 말단 화면·버튼·상태·필터에는 기능 ID(A1~I7, [9번 기능명세서](#) 근거)를 배지로 부착했고, 보관함·승인함 등 상태 필터는 [10번 데이터플로우](#)의 화면↔테이블 매핑(clips.status 등)을 따른다.

## 정책 노트

- 대부분의 대시보드 화면은 **스트리머·편집자 공용** — 편집자는 부여받은 권한(업로드·자동업로드)에 따라 동작이 달라짐
- **승인 대기함**은 스트리머에겐 승인·반려 화면, 편집자에겐 '내 요청 목록'으로 역할별 표시
- 유튜브 업로드는 항상 **스트리머의 채널 토큰**으로 실행 — 편집자는 채널 연동 불필요, 구글 로그인만
- **VOD 보관 60일** (치지직 프로 등급 기준) · 방송 종료 시 자동 생성 · 클립·레시피는 영구, 재렌더는 60일 내
- 핫키 바인딩은 OBS 단축키 시스템 사용 → 플러그인 영역에 위치
