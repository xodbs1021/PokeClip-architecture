> Google 로그인 `H1` → 역할별 메인 대시보드 → **제품 영역 → 페이지/화면 → 주요 액션** 순으로 읽는 정보 구조. 데이터베이스 필드명이 아니라 사용자가 실제로 접하는 화면과 행동을 기준으로 구성했으며, 각 항목은 [9번 기능명세서](#)의 기능 ID에 연결된다.

## Windows OBS 플러그인 · 스트리머

- **송출 설정 화면** `A1·A5` → SRT 병행 송출·자동 재연결
- **오디오 트랙 화면** `A2·A3` → 소스별 트랙 선택·라벨 (6트랙)
- **핫키 설정 화면** `A4` → 하이라이트 구간 마킹
- **송출 상태 위젯** `A6` → RTT·손실·재연결 상태 확인
- **업데이트 안내 화면** `A7` → GitHub Release의 Windows 빌드 확인

## 온보딩 (최초 1회)

- **플러그인 설치 화면** `A7` → Windows 빌드 설치·업데이트
- **방송 채널 연결 화면** `H2` → 치지직·SOOP 채널 등록
- **유튜브 연동 화면** `H3` → OAuth 채널 연결
- **연결 테스트 화면** `A1·A3` → SRT·트랙 매니페스트 확인

## 라이브 뷰 · 스트리머/편집자

- **라이브 대시보드 페이지** `D1~D4`
  - 저지연 재생·DVR 1h 시킹 `D1`
  - 자동·핫키 점프카드 확인 `C3·A4·D2`, 카드 만료 확인 `D2`
  - 카드 시점 이동·에디터 진입 `D4`
  - 채팅량 차트 확인 `D3`, SRT 송출 상태 확인 `A6`

## 클립 에디터 · 스트리머/편집자

- **클립 편집 페이지** `E1~E8`
  - 5초~3분 구간 선택 `E1`, 화면비율·크롭 선택 `E5`
  - 무음 필터·트랙 미리듣기·볼륨 조정 `E2`, 트랙별 웨이브폼 확인 `E3`
  - 브라우저에서 렌더 결과를 시뮬레이션하는 클라이언트 미리보기 `E6`
  - AI 자막 생성·편집 `E4`, 추천 제목 생성·수정 `E7`
  - 레시피 저장·렌더 요청 `E8·F1·F2`
  - 스트리머/직접 업로드 권한자는 업로드 `F3`, 권한 없는 편집자는 승인 요청 `H5`

## 클립 보관함 · 스트리머/편집자

- **클립 목록 페이지** `E8·F2` → 렌더 중·승인 대기·완료 필터, 레시피 열기·재편집
- **승인 대기함 페이지** `H5` → 스트리머 승인·반려 / 편집자 내 요청 확인
- **업로드 결과 페이지** `F2·F3` → 유튜브 링크·실패 사유 확인, 실패 잡 수동 재시도

## VOD (다시보기 · 60일 보관)

- **VOD 목록 페이지** `B5` → 남은 보관일 확인

- **자동화 템플릿 페이지** `F4` → 비율·자막·프리롤·공개범위 저장

- **운영 관리 페이지** `I4` → 계정·사용 현황 확인, 장애·업로드 실패 대응

## 정책 노트

- 라이브 뷰·클립 에디터·보관함·VOD는 **스트리머·편집자 공용**이며, 편집자는 부여받은 직접 업로드·자동 업로드 권한에 따라 동작이 달라진다.
- **승인 대기함**은 스트리머에겐 승인·반려 화면, 편집자에겐 '내 요청 목록'으로 역할별 표시
- 유튜브 업로드는 항상 **스트리머의 채널 토큰**으로 실행 — 편집자는 채널 연동 불필요, 구글 로그인만
- **VOD 보관 60일** (치지직 프로 등급 기준) · 방송 종료 시 자동 생성 · 클립·레시피는 영구, 재렌더는 60일 내
- A7은 **Windows 설치·GitHub Release** 범위로 한정한다.
- 핫키 바인딩은 OBS 단축키 시스템을 사용하므로 플러그인 영역에 위치한다.
