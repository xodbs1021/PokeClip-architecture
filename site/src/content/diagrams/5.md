> Target Production 관점의 AWS 클라우드 아키텍처 상세본 — AWS 공식 아이콘 스타일 · Region>VPC>AZ-A/B>Subnet 중첩 · 전 연결 프로토콜 라벨 · 선 스타일 5종(실선 동기/점선 비동기/굵은선 미디어/얇은선 제어/초록 CI·CD). 발표·멘토 리뷰용 클라우드 아키텍처 정본. 판단 근거 전문은 루트 `5_Pokeclip_CA.md`.

## 핵심 구성

- **Target Production이 본체**: AZ-A/B Multi-AZ(RDS Multi-AZ 자동 페일오버 · Redis Primary+Replica · ECS Multi-AZ 태스크 분산 · AZ별 NAT). MVP(dev) 차이는 하단 주석으로 분리 — Media EC2 1대 · ECS 최소 태스크 · RDS dev Single-AZ · Redis 단일 · NAT 최소 · SRT Dual Ingest 미적용.
- **Media EC2 내부 8모듈 파이프라인**: SRT Listener → MPEG-TS Demuxer → Multi-Audio Track Mapper → CMAF Segmenter → LL-HLS Origin·DVR(1h) → S3 Segment Uploader → Broadcast Lifecycle Publisher. MediaLive·MediaPackage·MediaConvert·Transcribe **의도적 배제**(ADR-003·013 — 자체 구현이 핵심 어필).
- **진입 분리**: HTTP/HTTPS(Route 53 → CloudFront/WAF → ALB → ECS)와 SRT UDP(OBS → SRT Entry EIP → Media EC2, UDP 9000)를 완전 분리 — **ALB는 SRT를 처리하지 않는다**.
- **OBS 이중 송출**: 본방(CHZZK·SOOP)과 PokeClip(SRT+MPEG-TS · UDP 9000 · ~10 Audio Tracks) 경로 분리.

## 비동기·잡 처리

SQS 4큐 + 각 큐 DLQ — 생산자·소비자:

| 큐 | 생산자 | 소비자 |
|---|---|---|
| Broadcast Event Q | Media Origin (`broadcast.started/ended`만) | Chat Collector · Clip Service (팬아웃) |
| Render Job Q | Clip Service | Render·Upload Worker |
| AI Job Q | Clip Service | AI Worker |
| Upload Job Q | Clip Service | Render·Upload Worker |

워커는 **멱등성 키 + visibility timeout 재시도 + 초과 시 DLQ 격리**(CloudWatch 감시) 전제. 잡 상태·AI 결과는 DB 직접 쓰기 없이 Clip Service API 경유(계약 1·8).

## 데이터

- **RDS PostgreSQL**: users · channels · editor_grants · broadcasts · jump_cards · clip_recipes(JSONB) · clips · job status · approval history · S3 object key — **미디어 바이너리 저장 없음**(메타·상태·관계·S3 포인터만, ADR-005).
- **ElastiCache Redis**: Session · Live Broadcast State · Chat Aggregation · SSE Fan-out · Live Chart Cache · SRT Statistics — 영구 저장소 아님.
- **S3**(논리 구분): CMAF Segments(DVR·VOD **한 벌 공유**) · DVR/VOD Manifest · VOD 60일 lifecycle · Rendered Clips · Subtitle Files · Chat Raw Archive · AI Artifacts.
- **CloudFront 오리진 분리**: 라이브 LL-HLS=Media EC2 / VOD·클립=S3. 매니페스트 짧은 TTL · 불변 세그먼트 긴 TTL.

## 운영·보안 · CI/CD

- CloudWatch 알람 9종: Media Ingest Down · SRT Disconnect · SQS Queue Depth · Oldest Message Age · Render Failure Rate · AI Job Failure · ECS CPU/Memory · RDS Connections · Redis Memory. Secrets Manager(YouTube 토큰) · IAM 최소 권한 · KMS(S3·RDS 암호화) · WAF · SG(SRT 소스 IP 제한) · Private DB 접근.
- CI/CD(초록 선): GitHub Monorepo → Actions(Test·Build) → ECR → ECS Rolling / Media EC2는 Actions → SSM Run Command 별도 경로. main push→dev 자동 · release tag→prod 수동 승인 · 로컬 docker-compose.

## 문서 불일치 판단 (최신 ADR 우선 — 상세 근거는 루트 5_Pokeclip_CA.md)
